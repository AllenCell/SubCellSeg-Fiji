SubCellSeg Fiji update site

This folder is a Fiji update site for the SubCellSeg Fiji plugin. Fiji reads it; there is nothing to download by hand.

In Fiji: Help › Update… › Manage Update Sites › Add Unlisted Site, then enter

  • Name: SubCellSeg
  • URL: https://allencell.github.io/SubCellSeg-Fiji/

Apply and Close, Apply Changes, restart Fiji, then run Plugins › Segmentation › SubCellSeg Setup….

Files here are written by the Fiji Updater itself (db.xml.gz and the jars under plugins/).
